MoonLit third-party notices
===========================

MoonLit is licensed under GPL-3.0-only. The application is planned to
redistribute a curated, process-isolated libobs runtime. The runtime is not
release-ready until every selected binary has a matching source, license text,
hash and build record in packaging/windows/.

Planned runtime components:

* OBS Studio / libobs: GPL-2.0-or-later
* FFmpeg libraries: license depends on the exact configure flags and selected
  components; no nonfree build may be used.
* x264: GPL-2.0-or-later
* Microsoft Visual C++ Redistributable: Microsoft redistribution terms.
* Optional NVIDIA, AMD and Intel encoder interfaces: supplied by the user GPU
  driver and not redistributed by MoonLit.

This notice is a development baseline, not a release artifact. Before a
release, add the complete license texts and source-offer information for every
file listed in the signed runtime manifest.
